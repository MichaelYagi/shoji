Infinite scroll

Shoji has no dedicated infinite-scroll plugin — its entire integration surface for both demos below is gallery.updateSlides(), a data-shoji-id marker on each thumbnail, and a plugin choice. Everything else on this page — fetching, rendering, scroll position, virtualization — is plain host code Shoji never sees. See the Infinite scroll guide for what those three touchpoints do and why.

Forward-only (append)

Each new page is appended to the item array and handed to updateSlides(). ActiveThumbnail is enabled here — tiles are only ever appended, never removed, so there's no risk of it tracking a thumbnail that's since disappeared.

Bidirectional (append + prepend)

A virtualized grid (see the guide for what that means) rebuilds the full item array from its own loaded-item map and hands it to updateSlides() every time that map grows. ActiveThumbnail is deliberately left off — this grid can unmount the exact tile it would be highlighting the moment that tile scrolls outside the rendered window.

Code: the Shoji integration

Forward-only — enable the plugin, then append and updateSlides():

const gallery = new Shoji(grid, { items: [], plugins: [Shoji.ActiveThumbnail] });

async function loadNextPage() {
  const newItems = await fetchNextPage();
  items = [...items, ...newItems];
  gallery.updateSlides(items);
  for (const item of newItems) grid.appendChild(renderThumb(item)); // sets a.dataset.shojiId
}

Bidirectional's updateSlides() call is identical in kind, just sourced from a Map instead of a plain array — sorted before every call, since Map iteration order is insertion order, not numeric order, and an older page's ids are always smaller but still inserted last: 

function sortedItems() {
  return [...itemsById.values()].sort((a, b) => idNum(a.id) - idNum(b.id));
}
gallery.updateSlides(sortedItems()); // called after every load, in both directions

Click-to-open, identical in both demos — resolved fresh from the id, never a captured index: 

function openById(id) {
  const index = sortedItems().findIndex((i) => i.id === id);
  if (index !== -1) gallery.open(index);
}

Everything else on this page — the sentinel/IntersectionObserver pattern, the fixed-row virtual list, the scroll-position math — is in the script above, and covered conceptually in the guide. None of it touches Shoji.
