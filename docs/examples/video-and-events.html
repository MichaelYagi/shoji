Code

The items array — three plain image items, then one video item:

const gallery = new Shoji('#gallery', {
  items: [
    { id: 'p1', src: 'photo-1.jpg', caption: 'Sunset over the bay' },
    { id: 'p2', src: 'photo-2.jpg', caption: 'Mountain trail' },
    { id: 'p3', src: 'photo-3.jpg', caption: 'City lights' },
    {
      id: 'v1',
      src: 'clip.mp4',
      video: { provider: 'html5' },
      sources: [{ src: 'clip.mp4', type: 'video/mp4' }],
      poster: 'clip-poster.jpg',
      caption: 'Sample video',
    },
  ],
});

// Dynamic mode has no scanned DOM to wire clicks from — the host owns
// the thumbnail markup, so the host wires the click too:
document.querySelectorAll('#gallery > a').forEach((el, i) => {
  el.addEventListener('click', () => gallery.open(i));
});

Every core lifecycle event, logged as it fires:

[
  'beforeOpen', 'open', 'afterOpen',
  'beforeSlide', 'afterSlide', 'slideItemLoad',
  'itemsUpdated',
  'beforeClose', 'close', 'afterClose',
  'destroy',
].forEach((name) => gallery.on(name, (detail) => console.log(name, detail)));

updateSlides() — diffs by id (falling back to src) and re-renders, firing itemsUpdated above:
