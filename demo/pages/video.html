Shoji.Video renders a { provider: 'youtube', id } item as a real YouTube embed — core's own native-<video> rendering can't play a YouTube URL at all. The last tile below is a plain data-shoji-video="https://youtu.be/..." link; Shoji's page scanning recognizes the host and extracts the video ID automatically, no JS item-authoring needed. No poster/thumbnail handling by Shoji itself — the grid tile's own <img> is just an ordinary page thumbnail the host supplies, unrelated to the lightbox slide. Autoplay is enabled too: press play (or Space) and it waits for the real YouTube player's own ended state before advancing, the same video-aware slideshow behavior a native <video> slide gets.
