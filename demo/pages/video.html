Shoji.Video renders a { provider: 'youtube' | 'vimeo', id } item as a real embed — core's own native-<video> rendering can't play either URL at all. Two tiles below (with a plain photo tile between them, so neither preloads as the other's neighbor) are plain data-shoji-video="https://youtu.be/..."/data-shoji-video="https://vimeo.com/..." links; Shoji's page scanning recognizes both hosts and extracts the video ID automatically, no JS item-authoring needed. No poster/thumbnail handling by Shoji itself — the grid tile's own <img> is just an ordinary page thumbnail the host supplies, unrelated to the lightbox slide. Autoplay is enabled too: press play (or Space) and it waits for the real player's own ended state before advancing, the same video-aware slideshow behavior a native <video> slide gets. Notice the caption starts hidden on a video slide — a caption sitting over the player's own controls would block them, so a toolbar toggle button reveals it on demand instead (showVideoCaption: true flips the default; see the Settings guide).
