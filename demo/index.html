Default selector scanning plain <a href><img> markup — no options object at all. The last tile is a video, auto-detected from a nested <video> element. The Autoplay plugin is enabled (plugins: [Shoji.Autoplay]) — open the lightbox and use the play button (or Space) in the toolbar; it plays through the video slide instead of timing out on it. ActiveThumbnail is enabled too — whichever tile below is currently open gets a blue outline, following along as you use the arrow keys or let the slideshow advance on its own. Fullscreen is enabled too — its toolbar button puts the whole lightbox into the browser's native fullscreen mode. RotateFlip is enabled too: the four rotate/flip buttons apply a non-destructive CSS transform to the current photo — navigate away and back (or just hit next/prev) and it resets, per DESIGN.md §4's "resets per slide". Zoom is enabled too: pinch, double-tap/double-click, ctrl+wheel, or the three toolbar buttons (zoom in/out/actual size) zoom into the current photo; drag to pan while zoomed.
